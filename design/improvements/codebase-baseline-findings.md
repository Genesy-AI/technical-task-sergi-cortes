# Codebase Baseline Findings

The architecture analysis found defects, design issues, and security gaps in the initial codebase.
They are listed with IDs in [05-assessment.md](../architecture/05-assessment.md).
Each item should become its own improvement document here, or a spec, when it is prioritized.
The highest value items are restoring the build and lint gates, a single lead field registry, and an asynchronous model for long-running workflows.

Related spec: none yet, this is the baseline for future specs.
